SC01 Plus Bedside Controller

Install the firmware on a WT32-SC01 Plus straight from your browser (Chrome or Edge on desktop; Web Serial is required).

  1. Plug the board into this computer with a USB data cable.
  2. Click Install, pick the board's serial port, and confirm.
  3. When the install finishes, the flasher asks for your Wi-Fi network and password.
  4. Open http://bedside.local/ (or the address shown) to build your layout and set up Home Assistant.
This browser does not support Web Serial. Use Chrome or Edge on a desktop. Web Serial needs a secure (https) page.

Always installs the latest release. Existing layout and settings are kept unless you choose to erase the device. All releases · Source and README

Untested on hardware: if the board does not show up as a serial port, hold BOOT while plugging it in.
